# Submission deployment checklist

No deployment was performed during this review. Local production behavior is verified; public-host configuration remains a launch gate.

- [ ] Commit the intended frontend source, including currently untracked `src/lib`, Detective components/routes, tests/fixtures, scripts, and documentation. Do not accidentally include `.env.local`, browser profiles, `artifacts/`, `node_modules`, or `.next`. Backend files already staged by their developer are outside this frontend review.
- [ ] Coordinate a public HTTPS backend with Evan. Confirm health, variables, layers, hotspots, and trends work there; ensure backend grid and snapshot assets are packaged. Localhost URLs cannot serve public visitors.
- [ ] Set frontend build environment `NEXT_PUBLIC_API_BASE_URL=https://YOUR-BACKEND.example` (without `/api`). This value is public and baked into the client bundle: rebuild after changing it.
- [ ] Have the backend operator set `EXTRA_CORS_ORIGINS=https://YOUR-FRONTEND.example` to the exact frontend origin, with no trailing slash. Include preview origins explicitly if needed. This is deployment configuration, not a requested backend source change. Both services need HTTPS to avoid mixed-content failures.
- [ ] Use Node-capable Next.js hosting with `frontend/` as the project root. `/explore` uses runtime server rendering; do not use static export. Next requires Node >=20.9; review used Node 24.16.0. Browser QA scripts require Node 22+.
- [ ] Run `npm ci --include=dev`, `npm test`, `npm run lint`, `npx tsc --noEmit`, `npm run check:api`, and `npm run build`. Build requires development tooling. Start with `npm start` using the platform-provided port; do not bind production to localhost. Only an install dry-run, not a fresh install, was performed in this workspace.
- [ ] Test the deployed browser: Home → Detective → Explorer → Home/About; direct `/detective` and `/explore` links; real Ottawa analysis and hotspot drilldown; requested coordinates versus NASA grid cell; timestamps, units, p-values, confidence intervals, source, warnings, and snapshot badges. CLI API success alone does not test browser CORS.
- [ ] Confirm fictional demo/hero labels and precipitation reliability warnings remain visible. Simulate backend failure and verify an explicit error with no fictional fallback. Statistical trends do not prove causes.
- [ ] Preserve texture credits and visible OpenStreetMap attribution. Community map tiles are best-effort, with no SLA; comply with the linked tile policy in ASSET-CREDITS.md. No offline/bulk tile downloads or paid service were added.
- [ ] Smoke-test physical mobile devices, Safari/Firefox, and the venue network. Local automated review used desktop Chrome, emulated mobile widths, and software WebGL; it cannot certify every GPU/browser. Prepare a clearly labeled recorded demonstration if connectivity fails.
- [ ] Review development dependency advisories: production audit reports zero; full audit reports seven moderate development-tool advisories in the typescript-eslint/minimatch chain. Audit dry-run proposed no fix. Resolve before submission if CI policy forbids all advisories; no dependency upgrade was made during this review.
